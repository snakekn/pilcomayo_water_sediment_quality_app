This application was developed using [R](https://www.r-project.org/) and [Shiny](https://shiny.posit.co/) and integrates spatial and tabular data for interactive analysis. Various packages were utilized in the development of this project and can be found on the project's [GitHub repository](https://github.com/snakekn/pilcomayo_water_sediment_quality_app).
