# River Remedy

**Comprehensive Multi-Year Heavy-Metal Contamination Analysis in the Pilcomayo River Basin (Bolivia)**

This repository is a collaborative project focused on analyzing long-term water and sediment quality across the Pilcomayo River system, combining work from historical baselines, acid mine drainage research, and modern lithium mining impact monitoring. The goal is to deliver robust data-driven visualizations, reproducible reports, and an integrated dashboard application for stakeholder engagement.
